# 필라테스 앱(영상 판매 + 수업 예약) 스토어 심사 통과 가이드

**조사일: 2026-08-19 / 대상: iOS App Store + Google Play, 한국 사업자·한국 스토어 배포**
**앱 성격: 필라테스 교육영상(디지털 콘텐츠) 판매 + 오프라인 수업 예약·수강권 관리**

---

## 0. 한 줄 결론

이 앱은 **"IAP를 반드시 써야 하는 것(영상)"과 "IAP를 쓰면 안 되는 것(오프라인 수업)"이 한 앱에 공존**하는 구조다. 스토어 심사에서 가장 리젝이 잦은 조합이며, 결제 경로 설계를 잘못 잡으면 양쪽 방향 모두에서 리젝된다. 기술 이슈보다 **결제 구조 · 계정 정책 · 환불 약관** 설계가 승패를 가른다.

## 1. 결제 구조 — 가장 중요한 판정표

| 판매 대상 | Apple | Google Play | 근거 |
|---|---|---|---|
| **녹화 교육영상 (VOD, 구독)** | **IAP 필수** | **Play 결제 필수** | Apple 3.1.1 / Play 결제정책 "video, education, fitness 구독 서비스" |
| **오프라인 스튜디오 수업 예약·수강권** | **IAP 금지, 외부 PG 필수** | **Play 결제 예외 (외부 PG 가능)** | Apple 3.1.3(e) / Play "헬스클럽 멤버십" 예외 |
| **실시간 1:1 온라인 PT** | 외부 결제 가능 | 외부 결제 가능 | Apple 3.1.3(d) "fitness training" 명시 / Play "퍼스널 트레이너 세션" |
| **실시간 그룹(1:다) 온라인 수업** | **IAP 필수** | Play 결제 필수 | Apple 3.1.3(d) "one-to-few and one-to-many must use IAP" |
| **비동기 자세 피드백(영상 올리면 나중에 코멘트)** | **IAP 필수** | Play 결제 필수 | Apple 심사팀 공식 답변: 비동기는 real-time 아님 |

### 절대 하면 안 되는 것 (실제 리젝 사례)

1. **코드 / QR / 수강권 번호 입력으로 영상 언락** — Apple 3.1.1이 "license keys, QR codes" 를 명시적으로 금지. 학원 앱이 정확히 이 구조로 리젝됨 (Apple Forums #748871, 2024-03).
2. **웹에서 결제 → 앱에서 재생만** — "앱에 결제 버튼이 없으면 안전"은 틀린 통념. B2B 피트니스 코칭 SaaS가 앱에 IAP·가격·회원가입이 전혀 없는데도 "앱이 외부에서 구매한 디지털 콘텐츠에 접근하는데 IAP로 구매할 수 없다"로 반복 리젝됨 (Apple Forums #811018). 웹 구매분 재생을 허용하려면 **3.1.3(b)에 따라 앱 내 동일 IAP를 반드시 병행**해야 한다.
3. **오프라인 수강권을 IAP 상품으로 등록** — 역방향 리젝(3.1.3(e) 위반).
4. **오프라인 수강권에 온라인 영상 열람권을 번들** — 묶는 순간 디지털 콘텐츠 판매로 재분류되어 IAP 강제.
5. **앱 내 "홈페이지에서 더 싸게" 유도 문구·링크** — 한국 스토어프론트는 여전히 금지. 2025년 Epic 판결로 풀린 건 **미국 스토어프론트 한정**. 앱이 링크하는 **외부 페이지에 결제 링크가 있어도 리젝**된 사례 있음 (Apple Forums #786489).

### 권장 설계

- 영상 탭 = StoreKit / Play Billing (구독 또는 **카테고리 번들**). 강의 수가 많으면 개별 IAP 상품 등록이 불가능하므로 구독·번들·크레딧 방식 필수.
- 예약 탭 = 자체 PG(토스페이먼츠/KCP/NICE) + Apple Pay.
- 두 탭을 **UI·데이터 모델·상품 카탈로그 수준에서 완전 분리**.
- 심사 노트에 조항 번호를 인용해 명시:
  > "Video lessons are sold via in-app purchase. Studio class reservations are for in-person services consumed outside the app and are therefore processed with an external payment method as required by Guideline 3.1.3(e)."

### 한국 대체결제 — 결론: 쓰지 마라

| 방식 | 9,900원 구독 시 개발자 수취 |
|---|---|
| Apple 소규모 프로그램 (15%) | **8,415원** |
| Apple 한국 외부결제 (26%) | 7,078원 ← **오히려 손해** |
| Google 구독 (15%) | 8,415원 |
| Google 대체결제 (11%) | 8,563원 (약 150원 개선) |

- Apple KR External Purchase: 26% 수수료, **한국 전용 별도 바이너리**, **IAP 병용 불가**, 매출 보고 월 1회(회계월 종료 후 15일)·납부 45일, 환불/구독관리 전부 개발사 책임. 연매출 100만 달러 미만이면 **Small Business Program(15%)이 확실히 유리**.
- Google User Choice Billing: 4%p 인하뿐인데 PCI DSS 인증 + 24시간 내 거래 보고 의무. 초기 사업자에게 ROI 없음.
- 참고: Google 신규 수수료 구조(서비스 10~20% + 결제 5%)의 **한국 적용 예정일은 2026-12-31**. 미국·영국·EEA는 2026-06-30 적용됨.
- 방송미디어통신위원회가 2026-08-12 인앱결제 강제 제재 논의를 공식 개시 — 향후 변동 가능성 있으므로 출시 시점에 재확인.

## 3. Google Play 체크리스트

### 🚨 최우선 — 마감 임박

**2026-08-31부터 신규 앱·업데이트는 `targetSdk = 36` (Android 16) 필수.** 오늘 기준 D-12. 미달 시 업로드 거부. (Play Console에서 2026-11-01까지 연장 신청은 가능)

### 계정 · 출시 전 필수

| 항목 | 요구사항 |
|---|---|
| **계정 유형** | **조직(Organization) 계정 강력 권장.** 개인 계정은 2023-11-13 이후 생성 시 **12명 테스터 × 연속 14일 비공개 테스트** 의무 → 3~5주 소요. 조직 계정은 이 요구가 적용되지 않는 것으로 알려져 있으나 **"조직은 면제"라는 명시적 문구는 공식 문서에 없음** → Play Console에서 실제 확인 필요 |
| **D-U-N-S 번호** | 조직 계정 필수. 발급 1~14일(경우에 따라 2~4주). **가장 먼저 착수할 것** |
| **등록비** | $25 1회성 |
| **Data safety 양식** | 수집 항목·목적·제3자 공유·암호화·삭제 메커니즘 선언. **국내 개인정보처리방침과 문구 불일치 시 반려** |
| **개인정보처리방침** | 공개 접근 가능한 **활성 URL**(PDF 불가), 앱 내 + 스토어 등록정보 양쪽 |
| **계정 삭제** | **앱 내 경로 + 웹 삭제 요청 URL** 둘 다 필수 (앱 삭제한 사용자도 접근 가능해야 함) |
| **Health apps 선언** | 운동 기록·진도 추적이 있으면 "Health and fitness app"으로 분류 → App content에서 선언 양식 제출. 과소·과대 신고 모두 반려 원인 |
| **콘텐츠 등급(IARC)** | 필수. 비게임이므로 GRAC 게임물 등급분류는 대상 아님 |
| **패키지** | AAB만 허용 (APK 불가) |

### 권한 설계 — 회피가 최선

- **위치 권한 요청하지 마라.** 스튜디오 위치는 정적 좌표 지도로 충분. 백그라운드 위치는 30초 시연 영상 + 선언 양식 요구 → 2025년 주요 반려 사유.
- **사진/동영상 권한도 회피.** 프로필 사진은 **Android Photo Picker**로 구현하면 권한 선언 불필요.
- 광고 SDK가 없으면 `AD_ID` 권한을 `tools:node="remove"`로 제거하고 Data safety에 "광고 ID 미수집" 신고 — 심사가 단순해짐.
- **Pre-launch report의 접근성 경고를 전부 제거**할 것. 사유 불명 반복 거부가 접근성 이슈였던 것으로 추정되는 사례 있음.

### 마케팅 문구

- "체형 교정", "디스크 치료", "통증 완화" 등 치료 효과 암시 표현 제거 (허위 건강 주장 조항).
- "최고", "1위" 등 최상급 표현 금지.
- 추상적 소개문보다 **구체적 기능 나열**로 작성 (메타데이터 정책 위반으로 4회 리젝된 국내 사례 있음).

### 2026년 환경 악화 신호

2025년 신규 앱 등록이 약 60만 개로 전년 대비 30% 증가(AI 코딩 도구 영향). Apple이 심사를 강화 중이며 일부 AI 앱 빌더가 업데이트 차단·삭제 조치를 받음. **2024~2025년 후기보다 체감 난이도가 높다고 가정할 것.**

### 리젝 사유 분포

Apple 미해결 이슈의 **40% 이상이 Guideline 2.1(앱 완성도)** — 데모 계정 로그인 실패가 압도적 1위다.

### 12명/14일 비공개 테스트의 함정 (Google, 개인 계정만)

1. "12명"은 **연속 조건**. 한 번이라도 12명 미만이 되면 시계가 **0으로 리셋**.
2. 옵트인만 하고 앱을 안 연 테스터는 거부를 유발. **실제 사용(engagement)이 숨은 5번째 요구사항.**
3. 옵트인은 4단계 전부 필요: 콘솔에 이메일 추가 → 링크 클릭 → "Become a tester" 클릭 → **동일 계정으로 Play스토어에서 설치**.
4. 실측 후기: 12명이 목표여도 **60~86명을 모아야** 안정적으로 유지됨.
5. 테스터·기간은 **다음 앱으로 이월되지 않음**.
6. 현실적으로 **15~17일**을 잡을 것.

→ **사업자등록이 있다면 처음부터 조직 계정으로 가는 것이 3~5주를 절약하는 최선의 수단.**

### Resolution Center 대응 팁

**할 것**
- 가이드라인 번호를 명시하고 조목조목, 감정 배제하고 사실 위주로.
- 스크린샷·화면 녹화·동작하는 데모 계정 첨부.
- **어느 화면/어느 빌드 기준인지 특정을 요구**하라. Apple이 구버전 기준으로 리젝하거나 문제 요소를 특정해주지 않는 사례가 실제로 있다.
- 리젝에 24시간 내 응답.
- 글로 설명하기 어려우면 **App Review 전화 상담 요청 가능**.

**하지 말 것**
- 기술 전문용어 나열 금지. "CLGeocoder, CAPBridgeViewController를 썼다"는 항변이 "리뷰어도 모르고 사용자에게도 설득력 없다"는 지적을 받은 사례가 있다.
- 심사 우회 목적으로 기능 숨기기 → 계정 정지 사유.
- 실질적 변경 없는 반복 항소.
- Google Play는 **동일 이슈 반복 리젝 시 앱 삭제·계정 정지**로 이어질 수 있음.

**현실**: 항소 보드는 대체로 리뷰어 편을 든다. **항소 전에 Plan B/C를 준비**하고, 일반적으로는 수정 후 재제출이 빠르다.

## 5. 한국 법규 — 스토어 심사와 직결되는 것들

### 5-1. 환불 정책 (이중 구조 필수)

**A. 디지털 콘텐츠(영상 강의) — 전자상거래법 제17조**

- 원칙: 7일 이내 청약철회.
- 제한 사유 5호: "용역 또는 디지털콘텐츠의 제공이 개시된 경우" — **단, 가분적 디지털콘텐츠는 제공 개시되지 않은 부분에 대해 청약철회 가능**.
  → 강의가 회차별로 나뉘면 **미시청 회차는 환불 대상**. "1강 봤으니 전체 환불 불가" 약관은 무효 리스크.
  → **회차 단위 시청 로깅 + 미시청 비율 부분 환불 로직**을 앱에 구현해야 한다.
- **제17조 제6항 단서 — 가장 놓치기 쉬운 조항**: 디지털콘텐츠는 "환불 불가" 표시만으로 부족하고 **시험 사용(미리보기) 제공이 의무**. 미이행 시 사업자가 제한 사유를 원용할 수 없어 **전액 환불 의무**가 발생한다.
  → **각 강의마다 무료 미리보기 클립 제공** 필수 설계.
- 환급 기한: **3영업일 이내**.
- 콘텐츠이용자 보호지침: 정기결제 임의해지 시 "기 이용일수 금액 + 잔여 대금의 10% 이내 손해배상금" 공제.

**B. 수강권·회원권(1개월 이상) — 방문판매법 계속거래**

- 1개월권, 3개월권, 1개월 이상 유효한 10회권, 정기 구독 전부 **계속거래**.
- 소비자는 **계약기간 중 언제든지 해지 가능**.
- 공정위 「계속거래 등의 해지·해제에 따른 위약금 및 대금의 환급에 관한 산정기준」 고시의 적용 업종에 **요가·필라테스업**과 **이러닝(전자학습)산업**이 2019년 개정으로 명시 포함됨.
- **위약금 상한 = 총 계약 대금의 10%** ("서비스 개시 여부 및 해지 시기와 관계없이").

```
환불액 = 총 결제금액 − 실제 이용분 − 위약금(총액의 10% 이내)
예) 120만원 1년권, 3개월 이용 → 120만 − 30만 − 12만 = 78만원 환급
```

- "환불 불가", "위약금 30%", "정상가 재산정 후 환불" 조항은 **무효 판단 가능성 높음**. 공정위가 헬스장·요가·필라테스 불공정 약관을 반복 시정한 이력 있음.
- 사업자 귀책(폐업·강사 이탈)이면 위약금 없이 미이용분 전액 환불.

## 7. 제출 직전 최종 체크리스트

**결제**
- [ ] 영상 = IAP/Play Billing, 오프라인 수업 = 외부 PG로 완전 분리
- [ ] 코드·QR·수강권번호로 영상 언락하는 경로가 전혀 없는지 전수 확인
- [ ] 오프라인 수강권에 영상 열람권이 번들되어 있지 않은지
- [ ] 앱 내 및 앱이 링크하는 외부 페이지에 결제 유도 문구/링크가 없는지
- [ ] IAP 상품이 심사 빌드에서 실제로 보이고 구매 가능한지

**계정·개인정보**
- [ ] 앱 내 계정 삭제 기능 (Apple) + 웹 삭제 URL (Google)
- [ ] 회원가입 필수 항목이 이름·연락처 수준인지 (생일·성별·신체정보는 선택)
- [ ] 소셜 로그인 토큰을 서버에 저장하지 않는지
- [ ] 로그인 없이 둘러보기(수업 소개·강사·가격·무료 샘플) 가능한지
- [ ] 권한 거부 시에도 나머지 기능이 동작하는지
- [ ] 개인정보처리방침에 국외이전 섹션 별도 기재 (Firebase/AWS 국가명 전부)
- [ ] 마케팅 수신동의 분리 체크박스 (기본 해제) + 야간 수신 별도 동의
- [ ] 접근권한 필수/선택 구분 고지 화면

**콘텐츠·메타데이터**
- [ ] 의료 주장 표현 제거 ("치료", "교정", "통증 완화")
- [ ] "운동 전 의사와 상담하세요" 고지 삽입
- [ ] 영상 배경음악 저작권 처리
- [ ] Google Play·안드로이드 언급 제거 (Apple 제출물)
- [ ] 스크린샷 규격 정확히, 앱 UI 60% 이상
- [ ] "beta", "demo", "test", "coming soon" 단어 미사용

**심사 대응**
- [ ] 데모 계정 + Demo Mode 버튼 + 데이터 프리셋
- [ ] 심사 노트에 결제 구조를 조항 번호와 함께 명시
- [ ] 심사 기간 내내 백엔드·개인정보처리방침 URL 가동
- [ ] Privacy Manifest + 서드파티 SDK 최신 버전 (Apple)
- [ ] targetSdk 36 + Data safety + Health 선언 (Google)

**법무**
- [ ] 환불 약관: 디지털 콘텐츠(회차별 부분환불 + 미리보기 제공) / 수강권(위약금 10% 상한)
- [ ] 사업자 정보 표시 (상호·대표자·주소·사업자번호·통신판매업 신고번호·연락처)
- [ ] 중개 모델이면 "통신판매 당사자 아님" 고지 + 스튜디오 신원정보
