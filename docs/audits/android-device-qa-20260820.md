## 요약

- **앱 고유 동작(A)은 에뮬레이터에서 전반 정상.** 뒤로가기(즉시종료 방지), 딥링크, 오프라인 배너·자동복구,
  키보드 가림 없음, safe-area, 회전, 큰 글꼴까지 통과. Play 심사에서 흔히 문제되는 "뒤로가기 즉시 종료"·
  "safe-area 침범"은 해당 없음.
- **결제(B)·영상(C)** 은 백엔드 연동과 실물 단말이 필요해 이번 QA 범위에서 확정 못 함. 특히 카드사 앱 왕복은
  실기기 필수. 실제 결제·SMS·알림톡은 수행하지 않음.
- **접근성(D)** 은 아이콘 버튼 aria-label 일부 누락이 유일한 "문제(경미)". Play pre-launch report 접근성
  경고 가능성이 있어 출시 전 보강 권장(프롬프트 D 판정과 일치).

## 미해결 / 실기기·백엔드 필요

1. **결제 앱 왕복 + 복귀 결과 반영** — 실기기 + 테스트 결제로 확인 필요.
2. **영상 재생/전체화면/백그라운드 정지/진도 저장** — 백엔드 연결 + 구매 영상 필요.
3. **TalkBack 전체 흐름 / 터치 타겟 48dp / 프레임 드랍** — 실기기 정밀 측정.
4. **아이콘 버튼 aria-label 보강** — 코드 개선 대상(별도).
5. 로그인 세션의 백그라운드 유지 — 백엔드 연동 후 확인.
