## 6. 정상 확인된 항목 (취약하지 않음을 확인)

- **SQL Injection**: mysql2 placeholder 100%. 사용자 입력이 SQL에 직접 삽입되는 곳 0건, LIMIT/OFFSET 전부 `Number()`+clamp, 동적 ORDER BY 없음
- **XSS**: 프론트 `dangerouslySetInnerHTML`/`eval` 0건, 백엔드 `stripHtmlTags` 적용
- **타인 데이터 접근(IDOR)**: 주문·장바구니·포인트·프로필·수강권 환불·알림·수료증·커뮤니티 수정삭제 전부 서버 소유권 검증 확인 (S-1 제외)
- **CORS/CSRF**: 와일드카드 없음, 화이트리스트 + SameSite=Lax + Origin 검증
- **파일 업로드**: 확장자 화이트리스트 + **매직바이트 검증** + UUID 파일명 + 경로 봉쇄 → SVG/HTML/PHP/EXE 차단
- **비밀정보**: 커밋된 `.env` 0건, 프론트 번들에 SECRET/KEY 노출 0건, keystore·google-services.json 미커밋
- **결제**: PortOne 확정 검증(세션 기반 user/email/금액/단일소비 재검증)과 웹훅 HMAC 서명 검증 정상. 주문 금액 검증·포인트 차감은 `hotfix/payment-amount-validation` 브랜치에 수정본 존재(이 브랜치 미포함)
- **인증**: scrypt+salt 해시, HttpOnly 쿠키, 로그인 실패 5회/15분 IP 차단, 로그인 실패 메시지 통일
