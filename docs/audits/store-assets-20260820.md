## 3. 앱 아이콘 — 판정 및 요구사항 (제작하지 않음)

**판정: 현재 런처 아이콘은 Capacitor 기본 템플릿이다** (시각 확인 완료).
- Android `mipmap-*` 전 밀도 + iOS `AppIcon-512@2x.png` 모두 파란 화살표+격자 기본 아이콘
- 이대로 제출하면 브랜드 불일치 + 심사 인상 저하

**디자이너/사용자에게 필요한 것**:
| 항목 | 요구사항 |
|---|---|
| Play 스토어 아이콘 | 512×512 PNG, 32bit, 1MB 이하 |
| Android 적응형 아이콘 | foreground/background 분리 (각 108dp 안전영역 66dp), Android Studio Image Asset로 mipmap 전 밀도 생성 |
| iOS 아이콘 | 1024×1024 PNG (알파 없음) — 추후 iOS 제출용 |
| 소재 제안 | 기존 브랜드 로고(`frontend/public/assets/images/이끌림로고.png` — ICL 체크 문양) 활용, 배경은 브랜드 크림/브라운 톤 |
| 주의 | 격자·기본 템플릿 요소 제거, 텍스트 최소화(작은 크기 가독성) |

## 4. 피처 그래픽 (1024×500) — 요구사항 정리 (제작하지 않음)

| 항목 | 요구사항 |
|---|---|
| 규격 | 1024×500 PNG 또는 JPG, 15MB 이하 |
| 구성 제안 | 좌측: 브랜드 로고+앱 이름 / 우측: 스튜디오 사진(`home/studio-main.jpg` 등 보유 사진 활용 가능) |
| 금지 | 가격·순위·수상 문구, 스토어 배지 워딩, 과도한 텍스트 (Google 가이드: 텍스트는 앱 이름 정도만 권장) |
| 참고 | 영상 프로모션을 쓸 경우 피처 그래픽이 유튜브 썸네일 배경으로 사용됨 — 중앙 재생버튼 영역 고려 |
